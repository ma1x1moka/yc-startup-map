description: Agent experience: how well an environment is set up for an agent to do good work — checks, architecture and free context.
---

AX asks a specific question: can an [agent](./Agent.md) orient, act and verify here without a human filling in the gaps? Fast deterministic checks, clear module boundaries, honest documentation and a project small enough to reason about are the load-bearing pieces.

It diverges from [DX](./DX.md) in interesting ways. Humans tolerate tribal knowledge and slow feedback because they accumulate memory across months; an agent arrives with none and leaves with none, every [session](./Session.md). Anything a newcomer would need explained is something the agent needs written down.

_Usage:_

"Agents do badly in this repo."

"No tests, no docs, and nothing runs locally. That's an AX problem, not a model one."
