**Website:** https://brewit.ai/ | **YC:** https://www.ycombinator.com/companies/brewit

Brewit builds role‑specific BI agents that are trained on a company’s database. By feeding sample queries, metric definitions, and column descriptions, the system creates a semantic layer that lets the agent understand the data schema. The agents can answer data questions, write SQL, and generate plots through a natural language interface, giving teams a conversational data analytics experience. Brewit was acquired, and the company is based in San Francisco with a small team of four.

_Usage:_

"How does Brewit train its BI agents on a company’s database?"

"Brewit trains agents by feeding sample queries, metric definitions, column descriptions, and other schema information to build a semantic layer that enables the agent to answer data questions, write SQL, and generate plots."
