**Website:** browser-use.com | **Twitter:** @browser_use | **GitHub:** github.com/gregpr07/browser-use

Founded by [Magnus Muller](./Magnus%20Muller.md) and [Gregor Zunic](./Gregor%20Zunic.md). San Francisco. Both from ETH Zurich.

**97,600+ GitHub stars** — one of the highest star counts ever for a YC company at seed stage. Raised **$17M seed**. Free open-source core + paid Browser Use Cloud.

Provides the framework for AI agents to control web browsers: filling forms, navigating sites, scraping structured data, automating web-based workflows. Unlike Playwright (deterministic test scripts), Browser Use lets an LLM decide how to navigate — handling sites it has never seen before, adapting to UI changes, completing goal-directed tasks without pre-written selectors.

The 97K stars metric tells the real story: developers discovered the tool, found it genuinely useful, and starred it at a rate that indicates real adoption. Open-source projects with that velocity typically have significant B2B revenue within 18 months.

Natural integration with [Metorial](./Metorial.md) (MCP agent orchestration) and [Multifactor](./Multifactor.md) (agent authorization) — together they form the infrastructure stack for safe, production-grade browser-based AI agents.

_Usage:_

"Why not just use Playwright or Selenium?"

"Those tools were designed for deterministic scripts. Browser Use lets an LLM decide how to navigate — it handles sites it's never seen before and adapts to UI changes that break Playwright selectors overnight."
