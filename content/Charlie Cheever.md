Co-founded [Expo](./Expo.md) with [James Ide](./James%20Ide.md), a framework and cloud platform (EAS) used by Airbnb, Bluesky, Walmart, SpaceX, and Tesla to build apps that run on iOS, Android, and web from one JavaScript codebase. Cheever, a Harvard CS graduate, previously worked as an SDE at Amazon, then as an engineer and manager at Facebook where he built Facebook Connect and the Facebook Platform, before co-founding Quora with Adam D'Angelo in 2009.
