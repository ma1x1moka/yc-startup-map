**Website:** https://continue.dev | **YC:** https://www.ycombinator.com/companies/continue

Continue builds an open-source coding agent that helps developers write code faster. The AI-powered tool is positioned for B2B customers in engineering, product and design, and it operates out of San Francisco.

The company was acquired by Cursor, highlighting its relevance in the developer-tool ecosystem.

_Usage:_

"What makes Continue's coding agent different from other AI code assistants?"

"Continue is open-source, so its model and integration can be examined and extended, unlike many proprietary assistants. It focuses on B2B engineering workflows and was notable enough to be acquired by Cursor."
