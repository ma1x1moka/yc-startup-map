**Website:** https://www.dagworks.io/ | **YC:** https://www.ycombinator.com/companies/dagworks-inc

DAGWorks provides open source frameworks and services designed to make AI agents and applications more reliable by standardizing how Python code expresses data, ML, LLM, and agent workflows. The company was acquired, marking a significant milestone for its developer-focused infrastructure. Its platform emphasizes an integrated development and observability experience that allows teams to collaborate and connect their AI systems more effectively.

The company operates two primary open source projects: Burr, which focuses on AI applications, and Hamilton, which handles AI pipelines and workflows. Both projects include self-hostable UIs as well as enterprise and SaaS offerings. By requiring only a one-line code change, developers can gain versioning, lineage, tracing, cataloging, and observability features out of the box, which helps reduce total cost of ownership and speeds up time to production.

_Usage:_

"How does DAGWorks handle observability for AI pipelines compared to building custom logging?"

"DAGWorks uses lightweight frameworks like Hamilton and Burr that integrate observability directly into the code structure. Instead of building custom logging, you add a single line of code to enable versioning, lineage, tracing, and cataloging automatically. This approach standardizes how workflows are expressed in Python, making it easier to maintain and monitor AI systems without significant overhead."
