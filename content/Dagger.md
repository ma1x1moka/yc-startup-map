**Website:** https://dagger.io | **YC:** https://www.ycombinator.com/companies/dagger

Dagger is a programmable CI/CD engine that executes pipelines as standard OCI containers. Developers can write pipelines in the same programming language as their application using a chosen SDK, allowing pipelines to be treated as code. The engine offers instant local testing, superior default caching, and full portability, so the same pipeline can run on a developer’s machine, a CI runner, a dedicated server, or any container hosting service.

Because Dagger runs entirely within the Docker ecosystem, it integrates with existing container workflows and lets teams use each other’s tools without learning new languages. Its cross‑language instrumentation and caching work consistently across environments, making it a flexible DevSecOps solution for B2B engineering teams.

The company, founded in the Winter 2019 batch, has a distributed team of 22 across multiple global locations and remains active in the developer tools space.

_Usage:_

"Can I run the same Dagger pipeline locally and on a CI runner without modifying it?"

"Yes. Dagger packages pipelines as standard OCI containers, so the exact same pipeline can be executed on a local machine, a CI runner, or any container hosting service without changes, providing instant local testing and consistent caching across environments."
