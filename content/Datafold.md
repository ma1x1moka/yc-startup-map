**Website:** https://datafold.com | **YC:** https://www.ycombinator.com/companies/datafold

Datafold automates manual work in data engineering, using agentic AI to handle day‑to‑day tasks such as testing and code reviews, as well as large one‑off projects like data platform code migrations. Companies from Perplexity to Disney use Datafold to unlock more value from their data by freeing data teams from repetitive work, accelerating developer velocity, and ensuring data quality. With a team of 30 based in New York City and remote, Datafold serves B2B analytics customers through its SaaS platform.

_Usage:_

"How does Datafold’s agentic AI differ from traditional data pipeline tools?"

"Datafold’s agentic AI automates both routine tasks—testing, code reviews—and large migrations, whereas traditional pipeline tools typically only manage static workflows and require manual scripting."
