**Website:** https://dataform.co | **YC:** https://www.ycombinator.com/companies/dataform

Dataform provides a platform for data teams to build, version‑control, and deploy SQL pipelines directly in their cloud data warehouses such as Snowflake, BigQuery, and Redshift. It streamlines the workflow by treating SQL code as software, enabling collaborative development and reliable deployments.

The company was acquired by Google Cloud in December 2020, giving Google Cloud a native solution for managing analytics pipelines. At the time of acquisition Dataform had a ten‑person team based in London and was positioned in the B2B analytics space.

_Usage:_

"How does Dataform differ from managing raw SQL scripts with a separate Git repo?"

"Dataform bundles version‑control, dependency tracking, and warehouse‑native execution into a single platform, so teams can develop and deploy pipelines without building a custom CI/CD pipeline for raw SQL scripts."
