**Website:** https://expo.dev | **YC:** https://www.ycombinator.com/companies/expo

Expo enables developers to write applications in JavaScript that run natively on Android, iOS, and the web. By combining the rapid iteration cycles and easy deployment of web development with the performance and device capabilities of native apps, it simplifies the mobile development process.

The platform includes Expo Application Services (EAS), a suite of cloud services designed to accelerate the release of Expo and React Native apps to app stores. These services help teams grow by streamlining the path from code to production.

Founded in the Summer 2016 batch, the company operates out of San Francisco and Palo Alto with a team of 40 engineers focused on B2B developer infrastructure.

_Usage:_

"How does Expo compare to using raw React Native for cross-platform development?"

"Expo wraps React Native with a managed workflow that adds automatic cross-platform support, fast iteration cycles, and easy deploys. It also includes Expo Application Services (EAS) to handle the complexities of getting apps to the stores, effectively reducing the friction of native app distribution compared to managing those processes manually."
