**Website:** https://featurepeek.com | **YC:** https://www.ycombinator.com/companies/featurepeek

FeaturePeek creates supercharged deployment previews of frontend sites that can be shared for rapid feedback. It adds a drawer overlay on top of the site, enabling reviewers to take annotated screenshots, capture recordings, leave comments, and create tickets on popular bug-tracking platforms.

The service requires no dependencies or code changes; teams can enable it simply by deploying to FeaturePeek. It is positioned as a developer tool SaaS for B2B engineering and product/design teams.

FeaturePeek was acquired.

_Usage:_

"Does FeaturePeek require code changes to add the overlay?"

"FeaturePeek injects a drawer overlay into the deployed site; no code changes or dependencies are required—just deploy to FeaturePeek and the overlay is added automatically."
