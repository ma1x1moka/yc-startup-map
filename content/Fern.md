**Website:** https://www.buildwithfern.com | **YC:** https://www.ycombinator.com/companies/fern

Fern solves the common pain points of API development by generating SDKs and API documentation that are typed, standardized, and always in sync. The platform allows companies to maintain a single source of truth, eliminating the drift that often occurs across multiple documentation and codebases.

Since launching in Winter 2023, the Brooklyn-based team of fewer than 40 engineers has built an open-source tool trusted by over 200 customers. Notable users include Square, Webflow, ElevenLabs, Auth0, and Intercom, who use Fern to power their developer and agent experiences. Fern was acquired, marking a significant milestone for the developer tools space.

_Usage:_

"How does Fern handle the synchronization between code and documentation compared to manual updates?"

"Fern generates both the SDKs and the API docs from a single source of truth, which ensures they are always in sync and typed. This removes the need for manual updates across different files, addressing the issue of unstandardized and out-of-sync APIs that often plague traditional development workflows."
