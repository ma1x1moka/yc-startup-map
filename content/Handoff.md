---
description: Deliberately moving work from one session to the next, carrying forward what matters and leaving the rest behind.
---

A handoff is a clear with preparation. Before ending the [session](./Session.md) you capture the state of the work — what is done, what is next, which decisions are settled and why — into something durable, then start clean and load only that.

Done well this is strictly better than a long session, because the new window contains a curated summary instead of an unedited transcript. The [skill](./Skill.md) is deciding what to carry: conclusions and constraints travel well, exploratory detours do not.

_Usage:_

"Should we keep pushing?"

"It's slipping. Hand off — write up where we are and start clean."
