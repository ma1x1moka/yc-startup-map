LiteLLM is an open-source LLM gateway that provides a Python SDK and FastAPI server for calling more than 100 language-model APIs—Bedrock, Azure, OpenAI, VertexAI, Cohere, and Anthropic—in a unified OpenAI format.

The project has earned over 50,000 stars on GitHub and is trusted by companies such as Rocket Money, Samsara, Lemonade, and Adobe. It is built for B2B use and is maintained by a 10-person team based in San Francisco.

LiteLLM raised a $1.6 million seed round from Y Combinator, Gravity Fund, and Pioneer Fund in the Winter 2023 batch and remains an active open-source project.
