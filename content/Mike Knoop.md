**Twitter:** @mikeknoop | **Website:** mikeknoop.com | **LinkedIn:** available

Co-founded **Zapier** with Wade Foster and Bryan Helmig — the no-code automation platform that became the default glue layer between web apps. Reached $5B valuation as one of the few capital-efficient, bootstrapped unicorns in tech.

Left Zapier after 10+ years to co-found the **ARC Prize Foundation** with [Francois Chollet](./Francois%20Chollet.md): $1M annual prizes for AI systems that pass the ARC-AGI reasoning benchmark.

Co-founded [Ndea](./Ndea.md) with Chollet in 2025. Knoop brings what Chollet lacked: the operational experience of scaling a company from 0 to unicorn — building distributed teams, navigating product decisions, and managing the business challenges that pure researchers underestimate.

The Zapier background is directly relevant: Zapier was built on connecting things that weren't designed to talk to each other. Ndea's program synthesis approach — composing programs from components — maps to the same modularity instinct.

_Usage:_

"How does Ndea's program synthesis approach differ from other AI code‑generation tools like GitHub Copilot?"

"Ndea composes whole programs by selecting and linking existing component modules rather than generating code token‑by‑token, mirroring Zapier's modular integration model; this lets the system build functionality from reusable parts instead of writing new code from scratch."
