**Website:** https://www.onegraph.com/ | **YC:** https://www.ycombinator.com/companies/onegraph

OneGraph built a GraphQL API that aggregates multiple web services, enabling developers to query Twitter, GitHub, Stripe, Salesforce, and other APIs through a single endpoint.
The startup was part of YC Summer 2018, had a small team of two engineers based in San Francisco, and focused on B2B, engineering, product and design.
In Q4 2021, OneGraph was acquired by Netlify, bringing its API integration capabilities into Netlify's platform.

_Usage:_

"What services can developers query through OneGraph's GraphQL API?"

"OneGraph allows developers to query Twitter, GitHub, Stripe, Salesforce, and other APIs through a single GraphQL endpoint, simplifying integration across multiple services."
