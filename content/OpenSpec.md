**Website:** http://openspec.dev | **YC:** https://www.ycombinator.com/companies/openspec

OpenSpec is an open-source, spec-driven framework that helps developers plan complex features by creating lightweight spec documents that serve as durable context for their coding agents. With more than 20k+ GitHub stars, it is one of the leading spec-driven frameworks and is used by thousands of developers and teams to plan and ship with the coding agent of their choice. OpenSpec's philosophy is to keep planning lightweight and iterative, matching the messy, evolving reality of software development without imposing rigid, bureaucratic workflows. The company is based in Sydney, NSW, Australia and operates in the B2B space.

_Usage:_

"Can OpenSpec be used with any coding agent, or does it lock you into a specific one?"

"OpenSpec is agent-agnostic; its spec documents provide durable context that any coding agent can consume, and the framework is used by teams with the coding agent of their choice."
