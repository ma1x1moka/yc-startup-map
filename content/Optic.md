**Website:** http://useoptic.com/ | **YC:** https://www.ycombinator.com/companies/optic

Optic helps developers collaborate at scale and build better APIs. Its open source tools make it easy to document API changes, review each other's changes during code review, and catch breaking changes before they reach production.
Optic applies version control concepts to API behavior, taking ideas from Git, code review, and CI.
Optic was acquired in 2018 and is used by Snyk engineers daily to improve the Snyk API.

_Usage:_

"Does Optic replace Swagger or Postman for API documentation?"

"Optic does not replace Swagger or Postman; instead it adds version control and review capabilities on top of API documentation, allowing teams to track changes, review them during code review, and detect breaking changes before deployment."
