**Website:** https://www.peer5.com | **YC:** https://www.ycombinator.com/companies/peer5

Peer5 provides a peer-to-peer (P2P) content delivery network (CDN) designed to improve live and on-demand video streams. As video quality shifts toward HD and 4K, traditional CDNs can struggle with peak demand, forcing publishers to pay for underutilized server capacity. Peer5 works alongside existing servers, offloading bandwidth to a peer network so that the delivery network grows stronger as viewership increases. Peer5 has since been acquired.

The service leverages HTML5 and WebRTC, enabling P2P delivery inside end-user web browsers without requiring software or plugin installations. It integrates with content providers' existing setups and supports various streaming protocols, players, and media servers. On average, Peer5 offloads 70% of bandwidth, increases server capacity by 20x, extends viewing time by 30%, and decreases rebuffering instances by 40%.

_Usage:_

"How does Peer5's P2P delivery work without forcing end users to install a client or plugin?"

"Peer5 relies on native web technologies like WebRTC and HTML5, allowing peer-to-peer bandwidth sharing directly inside standard web browsers with zero installation required from viewers. It acts as an overlay on top of existing media servers and traditional CDNs, supporting a wide range of streaming protocols and players to offload up to 70% of peak bandwidth onto the peer network."
