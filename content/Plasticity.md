**Website:** https://www.plasticity.ai | **YC:** https://www.ycombinator.com/companies/plasticity

Plasticity develops natural language processing APIs designed to help software engineers construct human-like language interfaces. Operating out of San Francisco as a B2B SaaS platform, the company provides tools aimed at enabling software systems to understand and communicate using natural human language.

Part of the Y Combinator Summer 2017 batch, Plasticity was subsequently acquired.

_Usage:_

"How do developers integrate Plasticity into their applications?"

"Engineers use Plasticity's SaaS APIs to add natural language processing capabilities directly into their products. The endpoints process input text to enable software applications to parse context and build human-like conversational interfaces."
