**Website:** http://preflight.com | **YC:** https://www.ycombinator.com/companies/preflight

Preflight is a no-code web testing platform designed to simplify creating and maintaining test suites. It claims to be 20x faster than manually writing tests in Selenium or Cypress. To address brittle test maintenance, Preflight interprets web pages as human users understand them, adapting to structural changes and automatically updating selectors whenever a test passes.

Beyond basic UI automation, Preflight includes a Workflow feature for orchestrating dependent end-to-end test sequences. It also streamlines API test creation by prepopulating API tests directly from the network calls captured during UI test execution, enabling teams to set up API tests in minutes.

Preflight was part of the Y Combinator Winter 2019 batch and operated with a team in Chicago and remotely. The company has since been acquired.

_Usage:_

"How does Preflight handle UI test maintenance compared to traditional frameworks like Selenium or Cypress?"

"Unlike traditional Selenium and Cypress setups that require manual selector updates whenever the UI changes, Preflight interprets web pages the way human users do. It adapts to design changes automatically and updates selectors whenever a test succeeds. Additionally, it accelerates backend testing by prepopulating API tests using the network calls captured during UI testing."
