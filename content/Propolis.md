**Website:** https://propolis.tech/ | **YC:** https://www.ycombinator.com/companies/propolis

Propolis builds intelligent browser agents that simulate real users to automate QA. It uses swarms of autonomous agents to test web applications, reducing manual testing effort.

Based in New York City with a two‑person team, the B2B company targets enterprises needing efficient quality assurance. Propolis was acquired.

_Usage:_

"How does Propolis differ from traditional automated testing tools like Selenium?"

"Unlike Selenium, which relies on scripted test cases, Propolis deploys swarms of autonomous browser agents that simulate real user interactions, providing more realistic and comprehensive testing coverage."
