**Website:** http://www.pullrequest.com | **YC:** https://www.ycombinator.com/companies/pullrequest

PullRequest provides code review as a service, helping development teams ship code faster with improved quality and lower costs. The platform combines automated static analysis with an on-demand network of code review experts to address code quality challenges.

Based in Austin, TX, the company operated with a team of 11 people and focused on B2B engineering and product design. PullRequest was acquired.

_Usage:_

"How does PullRequest differ from just using a CI/CD pipeline with linters?"

"While standard CI/CD pipelines handle static analysis and linting, PullRequest adds a human layer by providing access to a network of code review experts on demand. This hybrid approach aims to improve code quality and reduce costs by combining automation with specialized human review, rather than relying solely on automated checks or internal team reviews."
