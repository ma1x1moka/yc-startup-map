Founded by [Sanchit Monga](./Sanchit%20Monga.md) and [Shubham Malhotra](./Shubham%20Malhotra.md). San Francisco. Team of 5.

Inference engine for Apple Silicon that outperforms Apple's own MLX framework. Single SDK for multimodal AI models running fully on-device, with a central control plane for model rollouts, versioning, and access policies across thousands of devices — no cloud required.

Shubham Malhotra built MetalRT — the first complete multimodal inference engine for Apple Silicon — before RunAnywhere. That specific prior work is the technical moat: most founders approaching on-device AI don't have GPU kernel optimisation experience. Malhotra does.

Sanchit Monga comes from Intuit where he built mobile SDKs used by 50M+ active users. The combination of kernel-level performance expertise (Malhotra) and SDK distribution experience (Monga) is the right founding pair for this product.

The 10K GitHub stars at seed stage places RunAnywhere alongside [Browser Use](./Browser%20Use.md) as one of the most developer-resonant W25/W26 launches.

_Usage:_

"How does RunAnywhere's inference performance compare to Apple's own MLX framework on Apple Silicon?"

"RunAnywhere's engine, built on the MetalRT stack that Malhotra created, uses hand‑optimized GPU kernels for multimodal workloads, and the company claims it runs those models faster (higher throughput / lower latency) than Apple's native MLX framework on the same Apple Silicon hardware, thanks to that low‑level kernel expertise."
