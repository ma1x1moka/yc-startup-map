**Website:** https://sandboxbanking.com | **YC:** https://www.ycombinator.com/companies/sandbox-banking

Sandbox Banking provides a low‑code integration platform called Glyue, a web application that lets banks, credit unions, and fintechs quickly build and run connections to banking systems. Integrations can be web service APIs, batch ETL jobs, file or document transfer jobs, or event‑driven pub/sub services such as web hooks and Kafka streaming pipelines.

The company was acquired, marking its relevance in the Banking‑as‑a‑Service space. With a team of 33 spread across Boston, Los Angeles, and remote locations, Sandbox Banking serves the fintech and banking industries with a B2B focus.

_Usage:_

"Can I use Sandbox Banking’s platform to set up a batch ETL job that moves data from a legacy core system to a modern fintech app?"

"Yes. Sandbox Banking’s Glyue platform supports batch ETL jobs as one of its integration types, so you can configure a job that extracts data from a legacy core banking system, transforms it as needed, and loads it into your fintech application without writing extensive custom code."
