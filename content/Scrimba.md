**Website:** https://scrimba.com | **YC:** https://www.ycombinator.com/companies/scrimba

Scrimba is a coding course platform that hosts interactive screencasts, engaging over 120K monthly active students.

The platform’s new video format makes screencasts fully interactive for students, allowing them to run and edit code directly while watching, and it simplifies content creation for teachers.

With a vision to combine Stanford‑level quality with gym‑membership pricing, Scrimba aims to democratize software education from its base in Oslo, Norway, with a lean team of six.

_Usage:_

"How does Scrimba’s interactive video format differ from traditional screencasts?"

"Scrimba’s format lets students interact with code in real time within the video, rather than just watching a static demonstration, and it streamlines the creation process for instructors by providing tools that embed interactive elements directly into the screencast."
