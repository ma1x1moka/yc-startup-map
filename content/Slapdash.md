**Website:** http://slapdash.com | **YC:** https://www.ycombinator.com/companies/slapdash

Slapdash provides a low‑latency file system for cloud applications and the fastest interface in the world, called the Command Bar, to drive it. By bringing all apps together in one place, it makes modern computer work less tedious and more fun, turning routine workflows into a super‑fast experience. The company was acquired after its Winter 2019 batch and operates with a six‑person team across San Francisco and remote locations.

_Usage:_

"How is Slapdash’s Command Bar different from a regular terminal or OS launcher?"

"Slapdash’s Command Bar sits on top of a custom low‑latency cloud file system, letting you invoke any integrated cloud app directly from a single, fast interface rather than navigating separate tools or using a generic terminal. This design is meant to make workflows “insanely fast,” according to the company’s description."
