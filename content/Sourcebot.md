**Website:** https://www.sourcebot.dev | **YC:** https://www.ycombinator.com/companies/sourcebot

Sourcebot is an open-source code understanding platform for massive codebases. Used by thousands of engineers at NVIDIA, Red Hat, Wikimedia, and Arista Networks.

Understanding code — not writing it — is the primary bottleneck for large engineering teams. Sourcebot gives developers and AI agents the ability to regex search across millions of lines of code instantly, and ask questions across thousands of repos using any flagship reasoning model. Open-source and on-prem, deployed in enterprises within minutes.

_Usage:_

"How does Sourcebot differ from existing code‑search tools like Sourcegraph or GitHub’s code search?"

"Sourcebot combines instant regex search over millions of lines with AI‑driven Q&A across thousands of repos, letting you plug in any flagship reasoning model, and it’s fully open‑source and deployable on‑prem within minutes, whereas typical code‑search tools are SaaS‑only and don’t natively integrate large‑scale AI reasoning."
