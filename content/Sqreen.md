**Website:** https://www.sqreen.com/ | **YC:** https://www.ycombinator.com/companies/sqreen

Sqreen is an application security platform used by more than 800 organizations to protect, observe, and test their applications, APIs, and microservices. It analyzes in‑app execution in real time, delivering robust security while maintaining performance, unlike pattern‑based approaches that rely on static signatures.

Sqreen was acquired after establishing a presence in the B2B security market; the company, founded in YC’s Winter 2018 batch and based in San Francisco, employs around 120 people.

_Usage:_

"How does Sqreen’s security approach differ from traditional pattern‑based solutions?"

"Sqreen monitors the actual execution of code inside the application, analyzing behavior in real time rather than relying on predefined attack signatures. This lets it block threats based on what the app is doing, providing stronger protection without the latency or false positives common in pattern‑based firewalls."
