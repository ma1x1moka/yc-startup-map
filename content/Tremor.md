**Website:** https://www.tremor.so | **YC:** https://www.ycombinator.com/companies/tremor

Tremor offers a UI toolkit consisting of React components designed for building charts and dashboards. The library targets developers in B2B, engineering, and product design workflows, providing specialized tools for data visualization and web development.

The company participated in the Summer 2023 batch and operated with a team of two based in Zug, Switzerland. Tremor has since been acquired.

_Usage:_

"What's the integration story for adding Tremor to a dashboard project?"

"Tremor functions as a React component library, allowing developers to import its components to construct charts and dashboards within their existing React application stack."
