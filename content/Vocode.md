**Website:** https://vocode.dev | **YC:** https://www.ycombinator.com/companies/vocode

Vocode builds an open source voice AI platform that lets developers add conversational voice capabilities to their applications. The company focuses on B2B developer tools and generative AI, and its code is publicly available for customization.

Based in San Francisco with a three‑person team, Vocode’s offering is documented at docs.vocode.dev. The startup was acquired, reflecting its relevance in the voice AI space.

_Usage:_

"Is Vocode a hosted service or just an open‑source library that I need to run myself?"

"Vocode is an open‑source voice AI project, so you get the code and can run it on your own infrastructure; it isn’t a proprietary hosted service."
