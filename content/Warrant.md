**Website:** https://warrant.dev/ | **YC:** https://www.ycombinator.com/companies/warrant

Warrant provides an open source authorization service that allows developers to implement and enforce access control within their applications. It acts as a centralized platform for handling user permissions, enabling engineering teams to offload complex security logic and focus on building core product features.

The company operates in the B2B infrastructure space, offering developer tools via API to simplify the management of user authorization. Warrant was acquired, marking its exit from the startup phase after its Summer 2021 YC batch.

_Usage:_

"How does Warrant differ from building our own permission system?"

"Warrant serves as a dedicated, centralized service for authorization, which removes the need to build and maintain custom access control logic in your application. By using Warrant, your team can rely on an open source platform to handle user permissions, allowing you to focus development efforts on your core product features rather than infrastructure security tasks."
