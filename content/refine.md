**Website:** https://refine.dev | **YC:** https://www.ycombinator.com/companies/refine

Refine is a headless React framework that lets teams build enterprise web applications quickly. It removes repetitive tasks such as CRUD, state management, routing, authentication, access control, and i18n, saving developers days of work.

Since its launch, thousands of projects have been built by more than 15,000 monthly active developers. The community has grown to 16,000 GitHub stars, over 180 contributors, and 2,500 Discord members, reflecting its popularity among B2B, engineering, and product‑design teams.

Refine’s headless UI approach means it works with any custom design and ships with ready‑made integrations for Ant Design, Material UI, Chakra UI, and Mantine. It is backend‑agnostic and can connect to more than 15 backend services out of the box, including custom REST and GraphQL APIs, giving developers full control over styling and deployment.

_Usage:_

"How does refine handle authentication compared to other React admin frameworks?"

"Refine eliminates the need to write authentication boilerplate by providing built‑in support for authentication and access control. It works with any backend, so developers can plug in custom REST or GraphQL endpoints or use third‑party auth services, giving the same level of flexibility as other frameworks but with less setup time."
