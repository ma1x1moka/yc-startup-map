**Website:** https://www.transload.ai | **YC:** https://www.ycombinator.com/companies/transload

Transload helps logistics companies measure shipments using the security cameras they already have. A pallet, a couch, a tire – it captures the true size as it moves through the warehouse. Because 15% of shipments turn out to be larger than the sender claimed, catching those differences is worth about $50k per site per month in rebillings and improved trailer utilization. The startup is based in San Francisco, employs a team of three, and is currently active.

_Usage:_

"How does transload detect oversized shipments using existing security cameras?"

"Transload captures the true size of shipments as they move through the warehouse using the security cameras already installed. It then compares the measured dimensions to the sender's declared size, flagging any discrepancies. This allows logistics companies to catch 15% of oversized shipments, which can be worth about $50k per site per month in rebillings and better trailer utilization."
